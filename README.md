# Fahrenheit to Celsius Converter

## 📌 Overview
A simple C# console application that converts a temperature from Fahrenheit to Celsius. This was one of my first exercises to practice variables, user input, and basic arithmetic operations in C#.

##  Features
- Prompts the user to enter a temperature in Fahrenheit.
- Calculates the equivalent temperature in Celsius.
- Displays the result in the console.

## 🛠️ Technologies Used
- C# (.NET)
- Visual Studio Code

## 💻 How to Run
1. Clone the repository: `git clone https://github.com/laala/fahrenheittocelsius.git`
2. Navigate to the folder: `cd fahrenheittocelsius`
3. Run the application: `dotnet run`
